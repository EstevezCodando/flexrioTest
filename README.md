# Rio Flex

Protótipo de mobilidade elétrica para descobrir onde e quando recarregar um veículo, comparando preço, distância, disponibilidade, potência, tempo e incentivos.

## Rodar localmente

```bash
pnpm install
pnpm --filter @workspace/rio-flex run dev
```

O app é uma demonstração frontend com dados mockados. Não há autenticação, pagamentos ou integrações reais de carregadores nesta versão.

## Jornada principal

- Dashboard com recomendação inteligente
- Mapa de estações de recarga
- Detalhe e justificativa da recomendação
- Planejador de recarga
- Sessão simulada e resumo pós-recarga
- Monitoramento, histórico e recompensas
- Perfil e visão futura de Solar, Baterias e V2G
